# ورد PWA

هذه الحزمة جاهزة للنشر كتطبيق ويب تقدمي (PWA).

الملفات:
- index.html
- app.css
- app.js
- manifest.webmanifest
- service-worker.js
- icon.svg

## مهم
يجب نشر الملفات عبر HTTPS حتى تعمل خصائص PWA وService Worker.

## التثبيت
- Android/Chrome: يظهر زر تثبيت عند توفر شروط PWA.
- iPhone/Safari: مشاركة > إضافة إلى الشاشة الرئيسية.

## الحفظ
التطبيق يحتوي على حفظ محلي احتياطي + مزامنة سحابية عبر Supabase عند تسجيل الدخول.
